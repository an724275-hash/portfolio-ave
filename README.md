# ave dev — портфолио Артема

Статический сайт: HTML, CSS, JavaScript. Сборщик и Node.js для запуска не нужны.

## Локальный просмотр

Запустите `python deploy.py local-stage` и откройте http://localhost:8000.
`python deploy.py check` проверяет наличие файлов для публикации.

## Структура

- `index.html` — содержание, семь проектов и SEO-разметка; GRVM.LOL стоит последним и помечен как временно недоступный.
- `style.css` — базовые компоненты и локальные шрифты.
- `polish.css` — финальная композиция, фон и адаптивная визуальная настройка.
- `script.js` — навигация, проекты, тема и управление стикерами.
- `duck.js` — загрузка Blender-модели и управление курсором, касанием и стрелками.
- `assets/models/ave-duck.glb` — отдельная веб-модель утки.
- `tools/blender/ave-duck.blend` — редактируемый исходник Blender.
- `tools/build_duck.py` — повторная сборка `.blend`, `.glb` и контрольного рендера.
- `assets/` — локальные модели, шрифты и библиотеки.
- `stickers_json/` — анимированные стикеры.

Утка основана на CC0-модели `Rubber Duck Toy` автора Plat251 с Poly Haven /
BlendKit. Локальная сборка использует исходный `.blend`, один уровень
Catmull-Clark для гладкого силуэта и встроенные 1K PBR-текстуры. Источник и
лицензия сохранены в `tools/blender/vendor/polyhaven-rubber-duck/LICENSE.md`.
Для пересборки запустите Blender с `--background --python tools/build_duck.py`.
В браузере модель не использует непрерывное вращение: кадры рисуются только при
движении. При reduced motion она остаётся статичной. При недоступности WebGL
отображается запасной символ. Lottie-стикеры загружаются как SVG по мере
появления и останавливаются вне экрана, в неактивной вкладке и на скрытых
слайдах карусели.

Все ресурсы страницы загружаются с собственного домена. Внешние ссылки
на проекты и контакты открываются только по действию посетителя.

## Публикация

Обычный процесс: проверить изменения, сделать commit и `git push origin main`.
Автоматизация `python deploy.py push-git` добавляет только публичные файлы сайта,
создаёт commit при наличии изменений и отправляет текущую ветку в origin.
При уже подготовленных изменениях в индексе команда останавливается.
Инструменты разработки и документацию коммитьте отдельно.

Для GitHub Pages выберите main и корень репозитория в настройках Pages.
Домен задан в CNAME; его DNS и сертификат настраиваются отдельно.

`python deploy.py build-docker` собирает Docker-образ со всеми ресурсами.
`python deploy.py deploy-vps` действительно отправляет файлы через SSH/SCP:
проверьте адрес в deploy_config.json, настройте SSH-ключ и заранее проверьте
ключ сервера в known_hosts. Команда не удаляет старые файлы и не настраивает
Nginx, DNS или сертификаты. Нулевой код возврата означает завершение команды,
но доступность опубликованной страницы следует проверить отдельно.

## Сторонние ресурсы

Three.js 0.180.0, GLTFLoader, Lottie 5.12.2, Font Awesome 6.4.0 и Inter размещены
локально. Лицензии лежат рядом с файлами в assets. Фотографии и скриншоты проектов
не используются. GRVM.LOL расположен седьмым в общей карусели без ссылки, потому
что сервис сейчас не запущен. Данные о конверсии и неподтверждённый стек для новых проектов
не заявлены.
