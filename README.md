# ave dev — портфолио Артема

Статический сайт: HTML, CSS, JavaScript. Сборщик и Node.js для запуска не нужны.

## Локальный просмотр

Запустите `python deploy.py local-stage` и откройте http://localhost:8000.
`python deploy.py check` проверяет наличие файлов для публикации.

## Структура

- `index.html`: разделы страницы, десять проектов и SEO-разметка. GRVM.LOL стоит последним и помечен как временно недоступный.
- `style.css`: оформление, адаптивная сетка и локальные шрифты.
- `script.js`: навигация, карусель проектов, переключение темы, фоновые фигуры и анимированные стикеры.
- `assets/vendor/`: локальные Font Awesome и Lottie, подключённые в странице.
- `assets/webfonts/`: локальные шрифты и лицензии.
- `stickers_json/`: анимированные стикеры.

Текущая страница использует HTML, CSS и JavaScript с Lottie-стикерами.
3D-модель на ней не отображается. `polish.css`, `duck.js` и Three.js
не подключаются в `index.html`.

Все ресурсы страницы загружаются с собственного домена. Внешние ссылки
на проекты и контакты открываются только по действию посетителя.

## Материалы прежнего 3D-варианта

В репозитории сохранены `polish.css`, `duck.js`, `assets/models/ave-duck.glb`,
исходник `tools/blender/ave-duck.blend` и скрипт `tools/build_duck.py`.
Они относятся к прежнему варианту сайта. Инструмент публикации по-прежнему
включает эти файлы в публичный набор, но текущая страница их не загружает.

Модель основана на CC0-ресурсе `Rubber Duck Toy` автора Plat251 с Poly Haven /
BlendKit. Источник и лицензия сохранены в
`tools/blender/vendor/polyhaven-rubber-duck/LICENSE.md`.
Для пересборки прежней модели запустите Blender с
`--background --python tools/build_duck.py`.

## Публикация

Обычный процесс: проверить изменения, сделать commit и `git push origin main`.
Автоматизация `python deploy.py push-git` добавляет только публичные файлы сайта,
создаёт commit при наличии изменений и отправляет текущую ветку в origin.
При уже подготовленных изменениях в индексе команда останавливается.
Инструменты разработки и документацию коммитьте отдельно.

Для GitHub Pages выберите main и корень репозитория в настройках Pages.
Домен задан в CNAME; его DNS и сертификат настраиваются отдельно.

`python deploy.py build-docker` собирает Docker-образ со всеми ресурсами.
`python deploy.py deploy-vps` действительно отправляет файлы через SSH/SCP:
проверьте адрес в deploy_config.json, настройте SSH-ключ и заранее проверьте
ключ сервера в known_hosts. Команда не удаляет старые файлы и не настраивает
Nginx, DNS или сертификаты. Нулевой код возврата означает завершение команды,
но доступность опубликованной страницы следует проверить отдельно.

## Сторонние ресурсы

Lottie 5.12.2, Font Awesome 6.4.0 и Inter размещены локально.
Three.js 0.180.0 и GLTFLoader также сохранены локально для прежнего 3D-варианта.
Лицензии лежат рядом с файлами в assets. Фотографии и скриншоты проектов
не используются. GRVM.LOL расположен десятым в общей карусели без ссылки, потому
что сервис сейчас не запущен. Данные о конверсии и неподтверждённый стек для новых проектов
не заявлены.
